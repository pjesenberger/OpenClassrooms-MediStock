# MediStock

Pharmacy stock management app: medicines by aisle, stock updates with change history, user authentication.

**Stack:** Swift, SwiftUI, Firebase Auth, Firestore, MVVM, dependency injection, XCTest, GitHub Actions

**Setup:** add your own `GoogleService-Info.plist` in `MediStock/Configurations/`.
